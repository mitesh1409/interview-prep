# How does Node.js prevent blocking operations in a single-threaded environment?

**Event Driven Architecture**  

Built-in `events` module in Node.js.

We can emit events and write async callbacks or listeners that will be executed when a particular event occurs.

**Event Loop in libuv**  

libuv is a multi-platform support library with a focus on asynchronous I/O.

It takes care of non-blocking I/O operations.  

**Worker Threads**  

To handle CPU intensive operations we can have one or more worker threads.
