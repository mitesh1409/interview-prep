# Coding Question

What will be the output of the following:  

```javascript
console.log(10 + '5');

console.log('10' + 5);

console.log(10 - '5');
```

Output:  
105  
105  
5  

Explanation:  

This is JavaScript's **type coercion** at work, specifically how the `+` and `-` operators treat mixed types differently.

**The `+` operator is overloaded**

`+` does two jobs in JS — arithmetic addition and string concatenation. When either operand is a string, JS defaults to concatenation. It converts the other operand to a string and joins them.

So `10 + '5'` becomes `'10' + '5'` → `'105'`, and `'10' + 5` becomes `'10' + '5'` → `'105'`.

**The `-` operator has only one job**

`-` has no string meaning whatsoever — it only does arithmetic. So when JS sees `'5'`, it has no choice but to convert it to a number. `10 - '5'` becomes `10 - 5` → `5`.

The same single-purpose logic applies to `*`, `/`, and `%` — they're all purely numeric, so they always coerce strings to numbers.

**The mental model**

`+` asks: *"can I treat these as strings?"* — if yes, it does.
`-`, `*`, `/` ask: *"can I treat these as numbers?"* — they always try.

**A few edge cases worth knowing for interviews**

```js
console.log('5' - '3');      // 2  — both strings coerced to numbers
console.log('5' + + '3');    // '53' — unary + converts '3' to 3, then + concatenates
console.log(null + 1);       // 1  — null coerces to 0
console.log(undefined + 1);  // NaN — undefined coerces to NaN
console.log([] + []);        // ''  — both arrays coerce to empty strings
console.log({} + {});        // NaN
console.log([] + {});        // '[object Object]'
console.log({} + []);        // '[object Object]' (or 0 depending on context)
```

The last three are notorious interview trick questions — arrays and objects go through their `toString()` before the `+` operator acts on them.
